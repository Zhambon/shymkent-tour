# Шымкент — гастрономическая столица Казахстана
## Разработка стратегии развития гастротуризма и продвижения регионального турпродукта

**Автор проекта:** Жәнібек  
**Специальность:** Менеджер по туризму (г. Шымкент)  
**Профиль:** Менеджмент в туризме / Региональный турпродукт (РО 1.2 / РО 2.1)

### 📌 Содержание проекта:
1. **Паспорт проекта и Концепция:** позиционирование Шымкента как кулинарной столицы ЦА (+42% роста потока).
2. **Маркетинговый анализ и УТП:** синергия с новым международным терминалом аэропорта, «4 сезона вкуса».
3. **Гастрономические кластеры:** Ресторан *Sandyq* (этно-кухня), Чайханы Старого города (плов, самса, шашлык), Стритфуд-аллея Арбата, Агро-пояс (Сайрам, Казыгурт).
4. **Событийный менеджмент:** Международный фестиваль *«ДәмдәсTour» (DamDastour)*, чемпионаты по плову, цифровые ИИ-гиды *Visit Shymkent*.
5. **Экономика, KPI и Продвижение:** Рост среднего чека, мультипликативный эффект в HoReCa, инфлюенс-маркетинг.
